[ 3. MEKANISME TEKNIS PROTEKSI BANDWIDTH & AUTO-REJECT ]
--------------------------------------------------------------------------------
1. DETEKSI RESOLUSI OTOMATIS:
   - Sinyal OBS masuk ke server MediaMTX.
   - FFmpeg membaca metadata stream pada baris log pertama:
     "Stream #0:0: Video: h264, yuv420p, 1920x1080 [DAR 16:9], 60 fps"
   - Backend membaca nilai "1920x1080" atau "3840x2160" secara otomatis dalam 0.5 detik.

2. PENOLAKAN OTOMATIS (AUTO-REJECT):
   - Jika user berstatus FREE PLAN dan mendeteksi resolusi > 1080p (misal 4K):
     -> Backend seketika menghentikan proses FFmpeg (Auto-Kill) dalam 0.5 detik.
     -> UI Dashboard & Log menampilkan pesan error penolakan ramah:
        "Resolusi OBS Anda (4K 3840x2160) melebihi batas Free Plan (Max 1080p).
         Silakan ubah Output Resolution di OBS ke 1080p atau upgrade ke Pro Plan!"

3. DETEKSI & THROTTLING BITRATE:
   - FFmpeg log parser membaca bitrate real-time: "bitrate=8500.0kbits/s".
   - Jika user FREE PLAN melebihi 8.000 Kbps, backend memberi peringatan di UI
     dan menerapkan limiter paket "-maxrate 8000k -bufsize 16000k".

4. AUTO-STOP DURASI LIVE 4 JAM:
   - Backend memantau timer live: "time=04:00:00".
   - Jika user FREE PLAN mencapai durasi 4 jam, proses FFmpeg dihentikan secara
     otomatis dan mengembalikan status ke 'idle'.
